# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise results and code rather than people, and keep
discussions about competing tools factual. Harassment, personal attacks and publishing others'
private information are not tolerated.

Report unacceptable behaviour to **greyapp@protonmail.com**. Reports are handled confidentially.
