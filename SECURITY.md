# Security policy

## Reporting a vulnerability

Please report security problems in this repository (the harness, the workflows or the live site)
privately to **greyapp@protonmail.com** rather than in a public issue. We aim to reply within 7 days.

## A tested tool serving something harmful

If you see a tool in the benchmark serving malware, phishing or another serious threat, email the
same address with the link, the date and time, and a screenshot. We verify it and, if confirmed,
flag the tool on the live site as described in [SPEC.md §6.E](SPEC.md#e-privacy-and-safety).

## What this repository never contains

No credentials, no cookies or tokens from test runs (raw captures are stripped before publishing),
and no downloaded media.
